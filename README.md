# Príncipe da Paz – clipe animado de Natal

Clipe animado em página web, feito para a música de Natal **Príncipe da Paz**.

- Letra e música: Oscar Gomes da Silva Junior
- Animação: Claude, da Anthropic

## Como ver

Abra o endereço do GitHub Pages deste repositório e toque em "Começar". O clipe roda sozinho, sincronizado com a música.

## Estrutura

```
index.html                    página com todas as cenas e legendas
audio/principe-da-paz.mp3     música
.nojekyll                     faz o GitHub Pages publicar os arquivos como estão
README.md                     este arquivo
```

## Publicar no GitHub Pages

1. Em **Settings > Pages**, escolha **Deploy from a branch**.
2. Selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
3. Em cerca de 1 minuto o endereço aparece nessa mesma tela.
